# AchDyzlern Services™ website

A static, responsive, accessible cinematic website for AchDyzlern Services. It is intentionally dependency-free so it can be published on GitHub Pages, Cloudflare Pages, Netlify, or any static host.

## Publish

1. Enable GitHub Pages from **Settings → Pages → Deploy from branch → main → /(root)**, or connect this repository to a static host.
2. Replace `assets/logo.svg` with the approved source logo if the attached raster asset is replaced by a higher-resolution master.
3. Review every claim, contact detail, link, privacy statement, and IP notice before going live.
4. Add a privacy-compliant form provider only after approval; no form currently transmits learner data.

## Portrait video ad package

Recommended output: 1080×1920, 30–45 seconds, H.264, captions burned in only after text proofing, separate clean master without captions. Use original or properly licensed music and visuals. Generate visual plates without text, then add typography in editing to prevent AI spelling errors.

**Voice direction:** warm maternal female voice; calm authority, clarity, warmth and emotional safety. Pronounce the brand in voiceover as “Ack-Dyzlern”.

**Visual direction:** original ultracinematic black-to-red/orange/yellow streaks; photorealistic urban Indian context; accessible, stigma-free, strength-first imagery; no imitation of Netflix logos, title cards or proprietary assets.

**Voiceover / on-screen copy source:** use the approved wording in the project brief exactly after final legal and editorial approval. For a safe first edit, show short approved phrases: “Different minds. Limitless futures.”, “Digitally safe. Emotionally safe. Accessible.”, “AchDyzlern 360°™”, “Intelligence is unleashed.”

**Audio mix:** keep narration intelligible above music; use licensed trailer-style music with tension and release rather than fear-inducing effects around children or vulnerable learners. Provide captions, transcript, audio description and a reduced-motion cut.
